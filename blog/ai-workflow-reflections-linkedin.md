# LinkedIn Post: AI Workflow Reflections

Over the past year, my delivery workflow changed more than my tech stack.

I started by hand-coding Figma designs with AI as a side tool.  
Then screenshots.  
Then Cursor.  
Then Figma MCP.  
Then a build/verify agent loop with orchestration.

The surprising part: once generation got fast, writing code stopped being the bottleneck. Verification did.

AI could produce a page in minutes. I still had to check responsive states, regressions, dynamic content, and whether the result was actually maintainable. So I stopped trying to make one smarter agent, and built a system that could implement, verify, halt on disagreement, and ask a human for final review.

That changed how I think about engineering.

If AI can write most of the code, my value is not typing speed. It is:

1. knowing how to decompose the problem  
2. placing new tools on a real technical map  
3. defining constraints, permissions, and stopping conditions  
4. being "lazy" enough to automate the third time a task appears

Models create possibilities.  
Engineering systems turn them into reliable outcomes.  
People decide what is worth accepting.
